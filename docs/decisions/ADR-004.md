# ADR-004: Claude 연결과 비용 상한

- Status: Accepted — 사용자 결정, 2026-11-05
- 구현 추적: Issue #113, [티켓 20](../../tickets/analysis-verification/20-claude-client.md), 결정 D-01(`specs/analysis-verification/tasks.md`)

## 결정

- **공급자·연결:** Claude, Anthropic SDK(Messages API 도구 호출). 모델은 `claude-sonnet-5-5`(입력 $2 / 출력 $10 per 1M 토큰, 캐시 읽기 $0.20).
- **기본은 꺼짐:** `llm_enabled`가 켜지고, 비용 장부 파일이 지정되고, 환경 변수 `ANTHROPIC_API_KEY`가 있을 때만 클라이언트가 만들어진다. 키는 SDK만 환경에서 읽고 설정·저장소·Workflow 이력·로그·결과에 쓰지 않는다.
- **예외(에이전트 채팅):** 웹 에이전트 질문 답(`POST /agent/ask`)은 API가 만든다. 그래서 API 컨테이너에도 `ANTHROPIC_API_KEY`가 있고, 같은 비용 장부·긴급 중지 파일을 쓴다. 이 엔드포인트는 공개 엣지가 라우팅하지 않고(`AGENT_CHAT_ENABLED` 기본 꺼짐), 분석·샌드박스용 설정(`LLM_ENABLED`, `SANDBOX_KUBECONFIG`)은 API에 두지 않는다.
- **API 제약 반영:** Sonnet 5.5는 생각이 항상 켜져 있고 도구 호출 강제(`tool_choice` any/tool)와 `temperature` 등 샘플링 값을 거절한다. 그래서 이 값들을 보내지 않고 `effort`(Mapper·Tester `medium`, Fixer `high`)로 깊이를 조절하며, 생각 블록은 다음 턴에 그대로 되돌려 보낸다. 거절(`refusal`)이나 잘린 응답은 코드(`LLM_REFUSED`, `LLM_OUTPUT_TRUNCATED`)로 실행을 끝낸다.
- **다른 모델로의 자동 재시도(`fallbacks`)는 쓰지 않는다.** 재시도 모델의 요금으로 청구되어 비용 통제에 반한다. 거절은 사람 검토로 보낸다.
- **비용 상한(코드로 강제):** 마이그레이션당 $5, UTC 하루 $20, UTC 한 달 $100이 첫 기본값이며 설정으로 바꾼다(실제 실행으로 실측한 뒤 조정). 모든 호출은 호출 전에 최악의 비용(추정 입력 + `max_tokens`)을 장부에 예약하고, 호출 뒤 실제 사용량으로 정산한다. 한도를 넘길 수 있으면 호출을 보내기 전에 `BUDGET_RUN`·`BUDGET_DAY`·`BUDGET_MONTH`로 거절한다. 실패한 호출의 예약은 환불하지 않는다(청구되었을 수 있음). Activity 재시도도 같은 장부에 쌓인다. 차단 스위치: 파일 존재 또는 `CMP_LLM_DISABLED=1`이면 모든 호출이 `LLM_DISABLED`로 거절된다.
- **장부 저장:** 첫 사이클은 로컬 파일(배타 잠금, 원자적 교체, 합계만 저장하고 프롬프트·응답은 저장하지 않음). 워커가 여러 대가 되면 공유 저장소로 옮긴다.
- **에이전트 동작:** 예산·거절·공급자 오류는 해당 에이전트 실행을 이유 코드와 함께 `FAILED`로 끝내고 에이전트 루프는 다시 시도하지 않는다(Mapper는 검토 대기, Tester·Fixer는 실패). 일시 오류는 SDK가 이미 재시도한 뒤의 결과다.
- **전송 범위:** 모델에 보내는 것은 마스킹한 증거 요약·근거 주변 조각·마스킹한 로그뿐이다(비밀 값, `.env` 값 제외). 코드 전체는 보내지 않는다.

## 근거와 남는 일

- 사용 비용은 가격표(`cmp_agents/cost.py`의 `PRICES`)에서 계산한 추정이며, 청구서와의 대조(관리자 키로 사용량·비용 보고서 조회)는 운영 담당이 한다. 콘솔의 지출 한도·알림은 보조 수단으로 설정하되 이 ADR의 보장은 코드 상한이다.
- 가격표와 모델이 바뀌면 `PRICES`와 `llm_model`을 갱신한다. 모르는 모델은 가격이 없어 클라이언트를 만들지 못한다.
- 프롬프트 캐싱(안정적인 앞부분)으로 입력비를 줄인다. 사용량(캐시 읽기·쓰기 포함)은 장부 정산에 반영된다.
