# ENV-07 — Fixer가 추가한 변수 처리

## 담당
미정

## 상태
DRAFT — 방식과 담당 결정 필요.

## 목적
샌드박스 Fixer가 코드 수정 중 새 환경변수를 요구하게 되면(예: 새 설정 키), 그 키를 EnvPlan과 `.env` 참조에 어떻게 반영할지 정한다.

## 관련 요구사항
ENV-006, ENV-007.

## 선행 작업
ENV-05(EnvPlan).

## 검토할 선택지
1. EnvPlan에 `disposition: ADDED`를 추가하고, 값은 사람이 넣게 한다(결정 필요로 반환).
2. Fixer가 기본값을 함께 제안하고, 사람이 승인하면 `.env` 새 버전을 만든다(ENV-01의 버전 증가).
3. Fixer가 새 변수를 만들지 못하게 하고 코드만 고친다.

## 범위 (결정 후 확정)
- 선택한 방식의 계약 변경, `render_env` 처리, 재승인 흐름과의 연결

## 수용 기준 (결정 후 확정)
- [ ] Fixer가 추가한 변수가 원문 값 노출 없이 샌드박스·구축에 같은 방식으로 반영되거나, 명확히 거절된다.

## 결정 필요
- 4. `ADDED` 도입 여부와 담당(분석/샌드박스 담당 또는 민서)
